# ローカルモデルの選定記録

## 現行 v6（2026-09-17）

モデル構成はv5と同じです。UIを翻訳・字幕レイアウト・設定の3画面に整理し、独立した音声／字幕スイッチ、字幕位置の画面プレビュー、移動用フレームを追加しました。音声取得元は汎用のアプリ別WASAPIプロセスループバックへ拡張しています。

Chromeを独立したテスト用プロファイルで起動し、同梱の韓国語挨拶を再生。ブラウザのプロセスツリーから88,320サンプルを取り込み、「안녕하세요.」→「こんにちは」を確認しました（`tests/browser-capture-v6.json`）。対象外プロセスのテスト音が混入しないことも実機で再確認しています。

36件の回帰テストに合格。具体的なゲームのVCや、各ブラウザのタブ単位の分離は検証対象外です。アプリ単位の取得は、そのアプリの通知音・BGM・効果音も含みます。

## v5（2026-09-17）

認識を0.6Bと1.7Bから選択できるようにし、1.7Bを「少し重め」と表示します。どちらも4B未満です。4B級モデルそのものは今回搭載していません。読み上げはSupertonic 3のローカルモデルを同梱し、Windows韓国語音声がないPCでも日本語→韓国語の読み上げに対応しました。

画面の表示言語は日本語・韓国語・英語。設定は言語に依存しないIDで保存し、表示言語を変えても翻訳方向は変わりません。字幕はWindowsの透過色と縁取り文字で描画します。表示画面、9方向の位置、微調整、ドラッグ配置、クリック透過を備えています。

- 1.7B原モデル: https://huggingface.co/Qwen/Qwen3-ASR-1.7B
- 1.7B変換版: https://huggingface.co/thieunv-asilla/sherpa-onnx-qwen3-asr-1.7B-int8
- ローカル音声原モデル: https://huggingface.co/Supertone/supertonic-3
- 音声実行方法: https://k2-fsa.github.io/sherpa/onnx/tts/supertonic.html
- 音声変換版: https://huggingface.co/csukuangfj2/sherpa-onnx-supertonic-3-tts-int8-2026-05-11

1.7BもApache-2.0。SupertonicのモデルはOpenRAIL-Mで、モデルフォルダーに原モデルの `MODEL_LICENSE` を同梱しています。変換版に含まれているMITの `LICENSE` はコード用であり、モデルのOpenRAIL-Mを置き換えません。翻訳のNLLBは引き続き非商用ライセンスです。

### v5検証

32件の回帰テストに合格。両ASRで合成音声12条件が一致。1.7Bが出力することのある `language Korean<asr_text>` のような内部タグを、原文や翻訳に渡す前に除外しました。

Core i7-13700Kで、0.6Bの認識は0.41〜0.71秒、1.7Bは0.85〜1.35秒でした。発話終了待ち・翻訳・読み上げを含まない、今回の短い合成音声での測定です。1.7Bがどの実通話でも必ず改善するとは主張しません。

日本語を韓国語へ翻訳し、ローカル音声を生成、実際のWASAPI出力をプロセス別に再取得するテストにも合格しました。音量20→40のピーク振幅は約2倍、0は量子化ノイズ程度、取得した音声は「안녕하세요.」と認識されました。設定保存と再起動、3言語の画面、透明・枠なし・クリック透過のWindows属性も確認しました。

v5の完成.exeのオフライン統合診断にも合格しました。配布フォルダーは約4.58GB（0.6B・1.7B・翻訳・読み上げモデルを全て同梱）。診断中の最大ワーキングセットは3,702.3MiBでした。この測定は複数モデルを順番に試す診断全体の値で、通常通話の固定メモリ要件ではありません。

以下はv4時点の比較記録です。サイズやメモリ値はv5とは異なります。

## 採用

**Qwen3-ASR 0.6B / int8 ONNX / sherpa-onnx 1.13.8**。2026-01-29公開のQwen3-ASRは日本語・韓国語を含む30言語に対応し、0.6B・1.7Bを公開しています。今回の配布物は2026-03-25版の量子化モデルです。「最も新しい報告」ではなく、入手できる軽量なWindows CPUモデルを実機評価して選びました。

- 公式実装: https://github.com/QwenLM/Qwen3-ASR
- 原論文: https://arxiv.org/abs/2601.21337
- 量子化モデルの公式実行手順: https://k2-fsa.github.io/sherpa/onnx/qwen3-asr/pretrained.html
- 配布元: https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models
- 導入用ミラー: https://huggingface.co/csukuangfj2/sherpa-onnx-qwen3-asr-0.6B-int8-2026-03-25

ローカル処理: 16kHz音声 → 音量補正・Silero VAD → Qwen3-ASR → 認識文の言語判定 → NLLB-200 600M int8直接翻訳 → 字幕・読み上げ。

sherpa-onnx 1.13.8はQwenの言語ヘッダーを除去し、result.langとトークン確率が空です。そのため確率を捏造せず、仮名・ハングルと補助的なlangidで翻訳元を決めます。漢字だけの日本語も曖昧と判定し除外する制限があります。混在発話や短い英単語の判定にも限界があります。

## 比較した候補

| Moonshine | 日本語・韓国語モデルはあるが、言語ごとにモデル・条件が異なり、今回の自動切り替えにはQwenを選択 |

## 検証の範囲

Core i7-13700K、CPU 6スレッド。合成音声6種類を通常・小音量＋雑音の計12条件で評価。認識内容12/12一致、韓国語挨拶4/4を「こんにちは」に翻訳。認識時間0.38〜0.60秒。読み上げ・訳文生成・0.8秒の無音待ちは含みません。元音声をそのまま渡す予備評価では雑音付き男性挨拶で誤認識がありましたが、製品と同じ音量補正とパディングを通した最終処理では一致しました。

実通話の録音によるベンチマークではなく、大型Whisperとの一般的な優劣は結論していません。録音は通常動作では保存・送信しません。オンライン読み上げを選択した場合のみ翻訳文を音声サービスへ送ります。

## 配布版の測定結果

2026-09-17の.exe診断でローカル認識・日韓翻訳・Windows音声デバイス・プロセス別ループバック・最前面字幕を確認。配布サイズは旧版9,114,127,592バイトに対し、新版は約2,016,300,000バイト（文書更新により僅かに変化）、約78%削減です。これは新版フォルダー単体の比較で、旧版や開発環境を含むプロジェクト全体の容量ではありません。

診断プロセスの最大ワーキングセットは2,183.3 MiB（約2.29 GB）。長時間通話や発話の長さで変わるため、固定の必要メモリとは扱っていません。ASR・翻訳ともCPUのみです。

Windowsの実際のプロセス別音声取得 → 分節 → Qwen認識 → NLLB翻訳を、再生した合成の韓国語挨拶と日本語挨拶でも確認しました。韓国語は「안녕하세요.」→「こんにちは」、日本語は原文のまま表示する結果でした。Discord内の実通話を録音した試験ではありません。

導入したONNXとトークナイザー6ファイルは、sherpa-onnxのGitHub公式配布アーカイブとのSHA-256一致も確認しています。モデル内の `VERIFIED.json` に記録しています。
